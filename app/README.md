# Lyric Studio Android

Android WebView wrapper for the latest standalone Lyric Studio HTML.

- Application ID: com.tanvir.lyricstudio
- Minimum Android: 7.0 (API 24)
- Compile/target SDK: 34
- File imports: Android document picker
- File exports: Downloads/LyricStudio using AndroidBridge
- WebM/MP4 export support depends on the installed Android System WebView.

Build with JDK 17 and Gradle 8.9:
gradle :app:assembleDebug
